## Overview

**Mood Reimagined** is a Casualties Unknown Moodle resprite mod.

It changes the looks of the moodles to have different sprites for each stage of severity, adding a more diverse feel to the game while keeping its natural game look.

---

## Features

Adds different moodle sprites for mostly every moodle and stage of its severity.

A couple of moodles have not been changed and are listed below:
- Sleep
- Last stand
- Prosthetics
- Cargo Embedded

---

## Installation

1. Download the Zip file and open it.
2. Drag and drop `Moodreimagined.dll` into your `plugins` folder in `BepInEx`.
3. It's as simple as that.

> **Requirement:** Requires **CuCoreLib**, which is also included.

---

## Q&A

**Q: Some moodles are showing the wrong icon.**  
**A:** You probably downloaded an older version of the mod that had that bug, try updating the mod.

**Q: Can I use the code to make my own mod like this one?**  
**A:** Yes, absolutely! Just make sure to credit this mod. Be aware that any current bugs in this mod will apply to yours unless you fix them (if you manage to fix them, PLEASE inform me).

**Q: I don't like some of the moodles, how do I disable them?**  
**A:** There isn't a feature to do so, but you can download the source code, remove the moodles you don't like, and recompile it.

## Compatibility

### Compatible with:
- Most mods that don't change moodles.
- Multiplayer *(this mod is client-sided, I think)*.
- Somewhat compatible with [Resprite](https://nexusmods.com).
- Should be compatible with Translation mods.
- Stated to be compatible with [Old Moodles Reused](https://nexusmods.com).
- Maybe compatible with [One Too Many Moodles](https://nexusmods.com) *(untested)*.

### Not compatible with:
- [Resintro's Moodles](https://nexusmods.com)
- Other moodle mods.
- [No More Moodles](https://nexusmods.com) *(pretty self-explanatory, why does it even exist)*
- Probably not compatible with [Dynamic Moodles](https://nexusmods.com).
